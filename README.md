# Turbo Clash sunucusu

Çok oyunculu odalar için küçük bir WebSocket sunucusu (Node.js + ws).

- Render ayarları: **Root Directory** `server` · **Build Command** `npm install` · **Start Command** `npm start`
- Yerelde denemek için: `cd server && npm install && npm start` → oyunda sunucu adresine `localhost:8080` yaz.
